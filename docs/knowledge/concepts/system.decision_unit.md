## 是什么
同一只股票同一天可能触发好几条规则，你不需要逐条处理。系统把它们合成一个**决策单元**：每股每日一个，你的决定（采纳、否决、降级）就是针对这个单元做的。

## 怎么算 / 从哪来
把该股当日的全部候选的动作放在一起，合成建议动作：

- 同时有买入和卖出候选：建议动作为观察，并标记"冲突"（见[冲突与回避](system.conflict.md)）。
- 只有买入候选：建议动作为买入。
- 只有卖出候选：建议动作为卖出；如果你没有持仓，同时标记"回避"。
- 其余（只有观察类候选）：建议动作为观察。

单元还记录是否持仓，以及是否已经过了入场时点：影子入场按信号日后下一交易日开盘价，过了这个时点单元会显示"已晚"。只有"无冲突、未决定的买入单元"才会生成规则计划和 Agent 建议。

## 在系统里哪里看到
「今日」的决策单元卡：候选规则、输入值、计划、解读和冲突或回避标记。

## 注意
合成只是整理，不增加信息；建议动作来自规则，未经验证。
