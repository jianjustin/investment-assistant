## 是什么
月度收益衡量你整个账户这个月赚了多少，用的是券商月末总资金，而不是单笔交易的盈亏，所以包含了所有你没有记录的因素。

## 怎么算 / 从哪来
- **公式**：月度收益 =（本月末资金快照 − 上月末资金快照 − 区间净出入金）÷ 上月末资金快照。净出入金按出入金记录，入金为正，只计入上月末快照日之后、本月末快照日之内的记录；作废的出入金不计。
- **快照**：取该月最后一份有效快照；更早月份的快照不会冒充。任一端缺快照，显示"缺资金快照，无法计算"，绝不算成 0 或跨月份的收益。
- **分档**：大于 20% 为非常优秀；10% 到 20%（含 10%）为优秀；0 到 10%（含 0）为可行；小于 0 为需关注。阈值是配置项，默认如此。
- **对比**：同时列出同期 SPY 收益和超额收益。

资金快照按券商月末总资金录入，更正时必须指向当前有效的那份快照；出入金按笔录入，录错只能作废。

## 在系统里哪里看到
「复盘 → 月度复盘」和「资金」，页面显示"月度收益 +x.xx% · 档位 · SPY …"；月度推送由每日工作流的 `retro` 节点在上月有月末快照、且还没推送时发出。

## 注意
分档只是便于一眼读数的标签，不是对决策水平的评价；一个月的收益受仓位、市场和出入金时点影响很大。
