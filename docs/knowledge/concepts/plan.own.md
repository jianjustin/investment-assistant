## 是什么

规则计划只是算术结果。如果你对价位有自己的看法，可以在录入成交时选「自定」并提交自己的入场区间、止损和目标，系统把它们另存为一份自定（`own`）计划，这笔成交就关联它（v2.9 之前是采纳决定时提交，见[决定与执行依据](system.decision.md)）。

## 怎么算 / 从哪来

- 你提交四个价位：入场下沿、入场上沿、止损、目标 T1。必须都是正数，且满足 止损 < 入场下沿 ≤ 入场上沿 < 目标 T1，否则被拒绝。
- 自定计划与成交在**同一个事务**里写入，并记录它是基于哪份规则计划（`based_on_id`）。v2.9 起是 `plan-2`：`entry_type = zone_limit`，最长持有默认 10 个交易日（可填 3–30）。
- 它属于哪个单元：成交时刻你这只股票的活跃链所在的单元；没有就取成交日前 20 个交易日内最近一个有候选的单元；再没有就以成交日本身为信号日（不属于任何单元，也就没有链）。
- 有效期只有成交当天（它是写给这笔成交的）；ATR 按该单元的日线重新计算。
- 建议股数按你的价位重算：每股风险 = 入场区间中点 − 你的止损。

## 在系统里哪里看到

- 「复盘 → 交易与持仓」录入成交时的「关联计划」下拉里选「自定」（其余是活跃链的最新版、有效期覆盖成交日的规则基线、最近 5 个交易日内的自定计划，或「无计划」），见[执行状态与备注](review.execution_status.md)；之后和规则计划并列出现在计划页与复盘里。

## 注意

- 规则计划因财报或没有仓位空间而作废时，这些原因在自定计划里降为**提示**，状态总是 `ok`——这是你自己的决定，系统只提醒，见[计划状态](plan.status.md)。
- 价位由你负责：系统不判断你的价位好不好，规则的**未经验证**状态同样适用。
