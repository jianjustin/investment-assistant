## 是什么

规则计划只是算术结果。如果你对价位有自己的看法，可以在采纳时提交自己的入场区间、止损和目标，系统把它们另存为一份自定（`own`）计划，作为这次决定的执行依据。

## 怎么算 / 从哪来

- 你提交四个价位：入场下沿、入场上沿、止损、目标 T1。必须都是正数，且满足 止损 < 入场下沿 ≤ 入场上沿 < 目标 T1，否则被拒绝。
- 自定计划与决定在**同一个事务**里写入，并记录它是基于哪份规则计划（`based_on_id`）。
- 参考价和有效期与规则计划一样（T 日收盘；T+1 至 T+3），ATR 重新计算。
- 建议股数按你的价位重算：每股风险 = 入场区间中点 − 你的止损。

## 在系统里哪里看到

- 采纳时的「自定价位」选项，执行依据三选一（Agent 计划、规则计划、自定价位）见[决定与执行依据](system.decision.md)；之后和规则计划并列出现在计划页与复盘里。

## 注意

- 规则计划因财报或没有仓位空间而作废时，这些原因在自定计划里降为**提示**，状态总是 `ok`——这是你自己的决定，系统只提醒，见[计划状态](plan.status.md)。
- 价位由你负责：系统不判断你的价位好不好，规则的**未经验证**状态同样适用。
