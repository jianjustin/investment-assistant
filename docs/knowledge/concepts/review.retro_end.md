## 是什么
结束事件决定"这件事什么时候算完"。每个交易日批处理的复盘阶段按下面的规则检测，检测到才建[复盘卡](review.retro_card.md)。

## 怎么算 / 从哪来
**有买入成交的单元**只在买入的先进先出批次全部平掉时结束，结束类型 `position_closed`，结束日是平掉最后一批的那笔卖出的纽约日期。持仓期间链被作废、计划过期都不算结束，你还拿着仓位。

**没有买入成交的单元**，取以下几种里结束日最早的一个；同一天按这个顺序取：

1. `invalidated`：链被有效复查作废（结束日是该复查的日期），或参考计划按规则作废（结束日是决定的纽约日期）。
2. `stop`：参考计划的[影子](review.plan_shadow.md)第一条腿是止损或移动止损，结束日是该腿的出场日。
3. `target`：影子第一条腿是 T1，结束日是该腿的出场日。
4. `expired`：影子过期未成交，结束日是参考计划的有效期末日。

**计划外成交**：该笔买入的批次全部平掉，类型恒为 `position_closed`。

**参考计划**按顺序取第一个存在的：有持仓时只认你决定执行的那份；没持仓时依次是决定执行的计划、你决定时看到的 Agent 版本、规则计划 `plan-1`、`agent-1` 计划。一个计划都没有就不出卡。

**平仓方式**只描述、不是纪律判定：最后一笔卖出若在某个 `plan_stop` 信号日当天或其后 1 个交易日内，记"按止损"；否则持有期间最高价到过 T1，或卖出紧随 `plan_target` 信号，记"到 T1 后"；其余记"自行卖出"。计划外成交恒为"自行卖出"。

**检测窗口**：只认结束日不晚于当天、且在当天往前 5 个交易日之内的事件，补漏错过的批处理；更早的只能手动指定起点补出来。**同一结束事件只出一张卡**：单元没持仓结束、单元平仓、计划外成交各有固定的事件键，数据库保证不重复；同一单元平仓后再买再平是两件事，各出一张。

## 在系统里哪里看到
复盘卡页头的结束类型与结束日；「运行一览」里 `retro` 阶段的计数。

## 注意
结束只说明这件事不再有后续变化，不评价做得对不对。结束日用纽约交易日，平仓日期按成交时间换算。
