015 只作为仓库迁移文件新增，本轮不对真实数据库执行。老行新增字段保持 `NULL`，不猜测版本、不回填日期；缺可信来源的记录不能借新版本标签洗成可信历史。这一最小补强已随离线测试通过，但它只解决可识别/可隔离的问题，不替代不可变输入、供应商版本和严格历史可获得性证明；迁移文件尚未对真实数据库执行。

## 真实数据核验与历史上下文

当前环境连接配置中的 loopback 数据库返回 `OperationalError`；仅记录脱敏的错误类别，不披露 DSN。`ticker_signal_snapshots`、`strategy_scores`、`market_signals`、`event_studies` 当前行数及覆盖均为 **unknown / null，不是 0**。没有本轮 HTTP / UI 验收，也没有全量数据库回读。

本地既有原始文件共 108 个（US 65、A 股 43），SHA256 复核通过；22 个财务原始输入定位和 15 个季度样例复算通过。这证明限定范围的文件一致性、来源定位和算术，不证明供应商真实性、历史 first_seen、全部数据库归属/版本或当前 UI 数值。NVDA 收入直接单季与累计差分仍相差 100 万美元，应保留冲突，不能消除 TTM 的空值；TSLA 的 12 行也不是连续完整 12 季。

[跨市场研究报告](../../features/legacy/us-research.md)和 A 股报告（已于 v2.0.0 删除）记录的是各自交付时点的部署、数据和浏览器事实，原文保留。其历史 17,131 项财务事实、2,747 项算术检查、TEMP 数据库测试以及当时的 0 条记录，不能移作本轮当前数据库数量或验收结论。

## Phase 0 评审与 Phase 1 决定

[本轮 Phase 0 评审](reports/2026-10-17-phase0-review.md)只读使用截至 2026-10-15 的既有归档，重建八只股票的 132 个 SMA20 上穿事件。5/10/20 窗口有效 n 为 131/129/122，平均相对 SPY 超额为 2.3453/2.9158/5.8974 个百分点。这些是当前池、当前复权版本下的描述统计，不是可交易策略或收益建议。

全部正式 Gate 为 **HOLD**。缺可信历史信号、实际区制/VIX，加上相关重叠样本、当前池选择偏差、复权回填非严格 PIT、无成本与可实施入场模型，足以阻止依据未校正 CI 做保留结论。没有计算的信号保留 `n=null`，不能写成 `n=0`。

由 Gate 支持的下一步仅是输入可追溯性的最小补强与验收证据整理，而不是扩大 OHLCV/成分池采集、启用 FRED、购买一致预期或启动全组合回测。旧阶段的周数估算保留为历史估算，不形成新排期。
