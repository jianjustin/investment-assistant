# v2.7.0 我的成长闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交易结束后有讲给你听的复盘卡（宿主冻结事实 + Agent 单阶段起草 + 你审定），审定的教训进只追加、带版本的「我的知识」，被 Agent 按截止时间读取与引用、按影子结果回看表现；另有「就此计划讨论」与周度「你学到了什么」。迁移 027 新建十一张只追加表，批处理多一个阶段 `retro`（`stages-3`），Agent 工具 9 → 10。

**Architecture:** 纯函数层 `workbench/retro.py`（结束事件、冻结事实、决定文案、卡状态）、`workbench/knowledge_items.py`（知识字段校验、`know:` 引用、截止时间可见性）、`workbench/knowledge_perf.py`（表现回看）与 `agent/growth_check.py`（起草 / 回答校验、引用抽取）；Agent 侧 `tools.get_knowledge`、`agent/discuss_tools.py`、`graph.run_retro` / `run_discuss` 与按用途给工具；用例层 `workbench/retro_cards.py`（阶段 `retro`、审定、CLI）、`workbench/my_knowledge.py`（写 / 改 / 归档、表现、CLI）、`workbench/discussion.py`（任务式异步讨论）经 `api/routes/workbench.py` 暴露；前端新增复盘卡、我的知识、讨论页。

**Tech Stack:** Python 3.11 / FastAPI / psycopg 3 / PostgreSQL；LangGraph + 智谱 `glm-5.3`（不变）；Svelte 5 + Vitest；pytest（离线，SQL 测试用一次性库）。无新依赖。

**Spec:** [docs/specs/2026-10-28-v2.7-growth-loop-design.md](../specs/2026-10-28-v2.7-growth-loop-design.md)
