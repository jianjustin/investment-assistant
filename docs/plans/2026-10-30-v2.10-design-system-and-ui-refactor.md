# v2.10.0 设计标准与界面重构 Implementation Plan

> **For agentic workers:** 按 Task 顺序执行；每个 Task 的步骤用 checkbox（`- [ ]`）跟踪。实现子代理用别名 `sonnet`，审查用 `opus`（项目 `CLAUDE.md`）。**本 plan 待用户确认后才开始执行**；文末「需用户拍板」各项若被推翻，按回复改执行方式，正文不改（只增不改：以追加「确认结果」一节的方式记录）。

**Goal:** 把前端从「令牌直接到页面」补成「令牌 → 通用原语 → 领域原语 → 页面」三层：Tailwind 升 v4（CSS-first 令牌），shadcn-svelte 通用组件复制进 `web/src/lib/ui/`，自写领域原语（状态词汇表、版本标、截止时间、样本量、口径、涨跌数值、计划价位、数据块五态……），九个路由与全部组件迁上去，加八条静态守护与开发模式组件画廊 `#_ui`，落成活文档 `docs/design-system.md`；功能、接口、地址、与后端对齐的文案一字不改。

**Architecture:** 样式引擎先单独换代（Task 1：官方 codemod + 令牌类名一次改名，构建不红）；通用层（Task 2）与领域层（Task 3）在 `lib/ui/` 与 `lib/ui/domain/` 新建，不碰页面；守护（Task 4）以「按 Task 分片的基线允许列表」形态落地，基线只减不增；三个迁移波（Task 5–7）各自删掉自己那片基线；收尾（Task 8）删旧组件、守护全阻断、三套全量、发布准备。图表库不换，颜色运行时从 CSS 变量读。

**Tech Stack:** Svelte 5（runes / snippets）、Vite 6、TypeScript 5.9、Tailwind CSS v4（`@tailwindcss/vite`）、Bits UI 2（经 shadcn-svelte 1.7 复制）、`@lucide/svelte`、`svelte-sonner`、`tailwind-variants`、`cn`；ECharts 5、lightweight-charts 4 不变；Vitest 4 + Testing Library（jsdom）；pytest（离线文本扫描）。

**Spec:** [docs/specs/2026-10-30-v2.10-design-system-and-ui-refactor-design.md](../specs/2026-10-30-v2.10-design-system-and-ui-refactor-design.md)（§13：八项全部按「本文先按」确认；roadmap #81–#89）

## Review Focus

1. **令牌改名把语义弄反**：`text-muted` 在旧配置里是次要文字，在 shadcn 约定里 `muted` 是次级表面色；`accent` 旧义是品牌青绿、新义是悬停底色——直接套 shadcn 令牌会让 439 处次要文字近乎不可见、157 处链接变灰。→ Task 1 `test_no_legacy_token_names`；Task 2 `tokens.test.ts › every @theme color maps to a defined token`、`› AA contrast in both themes`。
