# v2.6.0 看懂系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在系统里看懂系统：「今日」顶部的运行一览、仓库内版本化的 88 张概念卡与「知识」菜单、「原理」页、四处就地展开、Agent 推理阅读视图、「标的」页四段重排与 K 线标注，另给 Agent 加只读工具 `get_concept`；不改任何计算口径与 Agent 流程，没有迁移。

**Architecture:** 知识层 `workbench/knowledge.py` 读 `docs/knowledge/`（概念卡 + 原理页），校验、用 `markdown-it-py` 渲染、进程内缓存，经 `api/routes/knowledge.py` 只读下发；`run_overview.py`（只读 `stage_runs`，纯函数拼句子）、`reasoning.py`（只读 `agent_runs` / `agent_tool_calls` / `agent_plan_versions` / `plan_reviews`，按运行组装阅读步骤）、`instrument_view.py` 与 `chart.annotate`（「标的」页的要点、关键数据与 K 线标注，纯函数）是新的只读用例；`agent/tools.py` 只新增 `get_concept`。前端新增「知识」路由、`ConceptTerm` / `RunOverview` / `AgentReasoning` 三个组件，挂到「今日」、计划页、「标的」页、推导视图与「数据」菜单。

**Tech Stack:** Python 3.11 / FastAPI / psycopg 3 / PostgreSQL；新增依赖 `markdown-it-py`、`PyYAML`（显式声明）；LangGraph + 智谱（不变）；Svelte 5 + Vitest + `lightweight-charts` v4；pytest（离线，SQL 测试用一次性库）。

**Spec:** [docs/specs/2026-10-28-v2.6-understanding-the-system-design.md](../specs/2026-10-28-v2.6-understanding-the-system-design.md)

## Review Focus

1. **坏卡拖垮别的功能**：一张卡 frontmatter 写错时，知识接口 503，但批处理、`get_concept` 之外的 Agent 工具、运行一览、「标的」页都照常；`catalog()` 不缓存失败。→ Task 1 `test_catalog_failure_not_cached`、`test_api_knowledge_503_lists_problems`；Task 3 `test_get_concept_when_catalog_broken_records_error_envelope`。

3. **运行一览的数字被「加工」**：计数必须与 `StageRecorder` 实际写出的行逐字段相同；`stages-1` 运行、缺行、旧 `detail` 缺键都不能报错。→ Task 3 `test_overview_counts_equal_recorder_rows`、`test_overview_stages_1_placeholder`、`test_describe_tolerates_missing_detail_keys`。
