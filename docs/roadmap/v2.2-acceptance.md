#### 已知问题

- **10-23 的区制快照停在第一次运行的部分样本**：第一次运行在网络故障下写入了 `regime-2` 快照（样本 26 只，`neutral`）。第二次用完整样本重算，内容不同，按只追加规则记为 `conflict`，没有覆盖。所以 10-23 的计划上下文、页面「市场环境」和 Agent 引用的都是 26 只样本的版本（结论同为 `neutral`）。之后的交易日由定时批处理首次写入，不受影响。
- **没有资金快照时，筛选报告的触发行写成「建议 null 股」**（推送第 5 条会是「建议 None 股」）：`no_equity` 时 `shares` 为空，`notify/templates.py` 的 `_screen_message` 与 `web/src/routes/Today.svelte` 的 `reviewText` 没有处理。计划卡片本身正确显示「缺资金快照，无法计算建议股数」。2026-10-26 已修复：推送与页面在没有股数时写「缺资金快照，无法计算股数」，服务重启后生效。
- **推送里的价位与宏观值带 6 位小数**（如「区间 250.770000–264.370000」「HY OAS 3.400000」），形态候选的 `ATR%` 写成小数 0.0456：模板直接输出 NUMERIC(…,6) 的值。2026-10-26 已修复：价位、风险金额、宏观值去掉多余的零，RS 保留 3 位，ATR 写成百分比（4.56%），与页面一致。
