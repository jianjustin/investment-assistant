### 第 1 条：画廊

- **逐元素比对**：在画廊页把所有过渡关掉，分别在 `data-theme=light` 和 `dark` 下读取每个可见元素的文字色、底色、边框色、`fill`、`stroke`。1258 个可见元素里，颜色在两种主题下完全不变的是 0 个；带文字的元素，文字色全部随主题变化。
- **深色逐屏目检**：令牌色板、按钮（含提交中与禁用）、徽标、表格（数字列、分组、置灰行、行展开、「显示更多」）、确认框与抽屉入口、页内与路由页签、表单（必填、错误、禁用）、提示与浮层、折叠、提示条（提示、降级、失败）、骨架、卡片、状态词汇全表、领域原语（版本、截止时间、样本量、口径、数值、价位、引用、来源）、数据块五态、页头与分段、图标、轻提示都随主题切换。

## 2. 计划表宽度（Task 9 附加检查）

在「今日」页按不同视口宽度量 `main` 的内容宽与可视宽：

| 视口 | `main` 可视宽 | 内容宽 | 结果 |
| --- | --- | --- | --- |
| 900 | 708 | 708 | 无溢出（< 1024 时计划表在自己的滚动容器里） |
| 1024 | 832 | 1242 | **整页横向滚动** |
| 1280 | 1088 | 1242 | **整页横向滚动**，页头右侧的按钮被推出可视区 |
| 1440 | 1248 | 1248 | 无溢出 |
| 1680 | 1488 | 1488 | 无溢出 |

计划表最小宽度约 1200px。≥ 1024px 时 `DataTable` 为了粘性表头用 `lg:overflow-visible`，卡片又跟着表格变宽，结果把整页撑出横向滚动。这就是 CHANGELOG 已知限制「宽表在 1024–1280px 可能撑出页面横向滚动」，现已在真实数据上确认（待修项 2）。截图：[`today-1440-light.jpg`](v2.10-acceptance/today-1440-light.jpg)、[`today-1440-dark.jpg`](v2.10-acceptance/today-1440-dark.jpg)（1440 下正常）。

## 3. 真实数据核对：运行记录状态

CHANGELOG 已知限制：`job_reports.status` 没有 CHECK 约束，遇到 `run` 域以外的值时，开发模式会抛错。用 `GET /api/jobs/reports?limit=500` 全量读取（共 85 行）：`success` 67、`error` 13、`degraded` 5，全在 `run` 词汇表里（`success / partial / degraded / failed / skipped / pending / running / error`）。运行记录页正常渲染。

## 4. 待修项（本版）

1. **375px 下「今日」计划卡溢出**：状态行的长标签不换行，超出 55px。`Badge` 原语要允许换行，或在卡片里给长文案换一种写法。§8.2 第 5 条因此只算部分通过。
2. **1024–1280px 下「今日」整页横向滚动**：计划表最小宽度约 1200px，在 `lg` 断点下不进滚动容器，撑宽卡片和页头。粘性表头和横向滚动要一起解决，或者在这个区间换回容器内滚动。

两项都只改前端样式，不涉及接口和口径。修好后补记在本文件。
